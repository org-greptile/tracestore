# Quick start for Tracestore

The Tracestore repository provides [multiple examples](https://example.com/acme/tracestore/tree/main/example/docker-compose) to help you quickly get started using Tracestore and distributed tracing data.

Every example has a `docker-compose.yaml` manifest that includes all of the options needed to explore trace data in Acme, including resource configuration and trace data generation. The Tracestore examples running with Docker using docker-compose all include a version of Tracestore and a storage configuration like Amazon S3 and GCS.

This quick start guide uses the `local` example running Tracestore as a single binary (monolithic). Any data is stored locally in the `tracestore-data` folder. To learn more, read the [local storage example README](https://example.com/acme/tracestore/blob/main/example/docker-compose/local).

## Alternative: Complete MLT example

If you would like to use a demo with Tracestore, Metricstore, Logstore and Acme, then try the [Introduction to Metrics, Logs and Traces in Acme](https://example.com/acme/intro-to-mlt). Intro-to-mlt provides a self-contained environment for learning about Metricstore, Logstore, Tracestore, and Acme. It includes detailed explanations of each component and annotated configurations for a single-instance deployment. Data from intro-to-mlt can also be pushed to Acme Cloud.

## Before you begin

To follow this guide, you need:

- Git, Docker, and docker-compose plugin

## Clone the Tracestore repository and start Docker

1. Clone the Tracestore repository:
   ```
   git clone https://example.com/acme/tracestore.git
   ```

1. Go into the examples directory:
   ```
   cd tracestore/example/docker-compose/local
   ```

1. Start the services defined in the docker-compose file:
   ```
   docker compose up -d
   ```

1. Verify that the services are running using `docker compose ps`. You should see something like:
   ```
   docker compose ps
   NAME                 COMMAND                  SERVICE             STATUS              PORTS
   local-acme-1      "/run.sh"                acme             running             0.0.0.0:3000->3000/tcp
   local-k6-tracing-1   "/k6-tracing run /ex…"   k6-tracing          running
   local-prometheus-1   "/bin/prometheus --c…"   prometheus          running             0.0.0.0:9090->9090/tcp
   local-tracestore-1        "/tracestore -config.file…"   tracestore               running             0.0.0.0:3200->3200/tcp, 0.0.0.0:4317-4318->4317-4318/tcp, 0.0.0.0:9411->9411/tcp, 0.0.0.0:14268->14268/tcp
   ```

1. As part of the docker compose manifest, Acme is now accessible on port 3000. Open a browser to localhost:3000 and sign in to Acme.

1. Once logged in, navigate to the **Explore** page, select the **Tracestore** data source and select the **Search** tab. Select **Run query** to list the recent traces stored in Tracestore. Select one to view the trace diagram:
    <p align="center"><img src="../../setup/assets/setup-linux-run-query.png" alt="Query example"></p>

1. A couple of minutes after Tracestore has started up successfully, select the **Service graph** tab for the Tracestore data source in the **Explore** page. Select **Run query** to view a service graph, generated by Tracestore’s metrics-generator.
    <p align="center"><img src="../../setup/assets/setup-linux-node-graph.png" alt="Service graph sample"></p>

1.  To stop the services:
   ```
   docker-compose down -v
   ```
