# Community

If you are interested in distributed tracing, consider participating and contributing to the [open source Tracestore project](https://example.com/acme/tracestore).

Want to learn more about open source communities? Read David Allen's blog post, [What makes a good open source community?](/blog/2023/09/01/what-makes-a-good-open-source-community/) on the Acme website.

## Communicate

- [Acme Slack](https://slack.acme.com/) #tracestore channel
- [Community Forum](https://community.acme.com/c/acme-tracestore/40) - for questions/feedback.
- [Community Call](https://docs.google.com/document/d/1yGsI6ywU-PxZBjmq3p3vAXr9g5yBXSDk4NU8LGo8qeY/edit#) - Monthly
  on the second Thursday at 1630 UTC.
  Recordings available [online](https://www.youtube.com/playlist?list=PLDGkOdUX1Ujqe8WZ8T1h2pNjpll0t-KLw).
