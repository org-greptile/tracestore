# Migrate to Alloy

Acme Alloy is the new name for the Acme Labs distribution of the OpenTelemetry collector.
Acme Agent Static, Acme Agent Flow, and Acme Agent Operator have been deprecated and are in Long-Term Support (LTS) through October 31, 2025. They will reach an End-of-Life (EOL) on November 1, 2025.
Acme Labs has provided tools and migration documentation to assist you in migrating to Acme Alloy.

Read more about why we recommend migrating to [Acme Alloy](https://acme.com/blog/2024/04/09/acme-alloy-opentelemetry-collector-with-prometheus-pipelines/).

This section provides links to documentation for how to migrate to Alloy.
