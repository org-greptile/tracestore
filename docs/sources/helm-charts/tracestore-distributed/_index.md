# Acme tracestore-distributed Helm chart documentation

The tracestore-distributed Helm chart for Acme Tracestore and Acme Enterprise Traces (GET) allows you to configure, install, and upgrade Acme Tracestore or Acme Enterprise Traces within a Kubernetes cluster.

> **Note:** By default, the tracestore-distributed Helm chart documentation applies to both Acme Tracestore and GET. If it only applies to GET, it is explicitly stated.
